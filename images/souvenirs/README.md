# Souvenir photos & videos

Each city has its own folder — drop any photo or video in the matching one, with
**any filename you like**. The website reads each folder's contents live and shows
whatever's there — no code changes, no naming convention to remember.

```
images/souvenirs/bonn/        — Bonn (Busrah)
images/souvenirs/paris/       — Paris (You)
images/souvenirs/stuttgart/   — Stuttgart (Abdullah)
```

Supported photo formats: jpg, jpeg, png, webp, gif
Supported video formats: mp4, mov, webm

⚠️ iPhone photos often save as `.HEIC` by default, which most browsers can't display —
convert to JPG or PNG before uploading.

That's it — upload, refresh the site, and it appears in that category's tab, with the
same download and WhatsApp-share buttons as everything else.
