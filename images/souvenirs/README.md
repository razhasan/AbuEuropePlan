# Souvenir photos & videos

Drop files here named by category. Any slot that exists will automatically appear in the
"Permanent Souvenir Photos" tab on the website for that category — no code changes needed.
Slots with no file just don't show up, so you never have to fill them all at once.

## Photos

```
bonn1.jpg / bonn1.jpeg / bonn1.png / bonn1.webp
bonn2.jpg
...
bonn30.jpg

paris1.jpg
...
paris30.jpg

stuttgart1.jpg
...
stuttgart30.jpg
```

Any of the four extensions above works for a given number — you don't need to match the
extension exactly, just the number.

⚠️ iPhone photos often save as `.HEIC` by default, which most browsers can't display —
convert to JPG or PNG before uploading.

## Videos

Same idea, with `vid` inserted before the number:

```
bonnvid1.mp4 / bonnvid1.mov / bonnvid1.webm
bonnvid2.mp4
...
bonnvid30.mp4

parisvid1.mp4
...
parisvid30.mp4

stuttgartvid1.mp4
...
stuttgartvid30.mp4
```

Videos show as a tap-to-play tile in the grid, alongside the photos.

Need more than 30 slots in a category? Just ask for the grid to be extended.
