# Souvenir photos

Drop souvenir photos here named exactly:

```
souvenir1.jpg
souvenir2.jpg
souvenir3.jpg
...
souvenir12.jpg
```

Any of these 12 slots that exists will automatically appear in the "Permanent Souvenir Photos" grid
on the website for every visitor — no code changes needed. Slots with no file just don't show up,
so you don't have to fill all 12 at once.

Need more than 12? Just ask for the grid to be extended.
